# Refining Plots (Albion Online)

Profit calculator for refining stations placed on Albion Online city plots:
minimum profitable tax (silver per 100 nutrition), profit per 100 nutrition and margin,
favorite food (x2 nutrition), payment to food donors, plot payback, daily profit from
crafting capacity, owner profit per tier / enchantment, refiner profit (recipe + return
rate, manual prices or live prices from the Albion Online Data Project).

A single static page (`index.html`), every field is saved in the browser (localStorage).
Live at https://plot.dwa.gold
